### Selected Open-Source SEO & AI Tooling

- **[RAG-bot-checker](https://github.com/MarcoBonomo/RAG-bot-checker)** — One-click utility auditing `robots.txt` access and directives across major AI & RAG crawlers (*GPTBot, ClaudeBot, PerplexityBot, Google-Extended, Applebot-Extended*).
- **[poncho-prompt](https://github.com/MarcoBonomo/poncho-prompt)** — Technical SEO Health Dashboard specification powered by **Streamlit + Lumar GraphQL API** for automated crawl-health scoring, URL drill-downs, and money-page governance.
- **[Alt-Text-Wizard](https://github.com/MarcoBonomo/Alt-Text-Wizard)** — Scalable accessible image `alt`-text generator built on **Vision LLMs**, featuring custom product taxonomy rules, batch processing, and API cost telemetry.
- **[url-matcher](https://github.com/MarcoBonomo/url-matcher)** — Automated website migration redirect mapper (**Python + Streamlit**) matching legacy to target URLs via path structure, `<title>`, and `<h1>` similarity.
- **[SEO-URL-checker](https://github.com/MarcoBonomo/SEO-URL-checker)** — Python inspection script for verifying HTTP status chains, indexability directives, and canonical tags across URL lists.
